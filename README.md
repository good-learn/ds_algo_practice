# 📊 Classic Algorithms Summary Table of Iconic Eponymous Algorithms

| Algorithm | Named After / Creators | Primary Problem Solved | Time Complexity | Space Complexity | Best Use Case / Real-World Application |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Dijkstra's Algorithm** | Edsger W. Dijkstra | Single-source shortest path on weighted graphs with **non-negative** edge weights. | $O((V + E) \log V)$ (with min-heap) | $O(V + E)$ | GPS mapping, packet routing in networking (OSPF protocol). |
| **Kruskal's Algorithm** | Joseph Kruskal | Finding the Minimum Spanning Tree (MST) by sorting edges and using a Disjoint Set Union (DSU). | $O(E \log E)$ | $O(V + E)$ | Designing low-cost cable/fiber-optic networks, circuit board layout. |
| **Prim's Algorithm** | Robert C. Prim & Jarník | Finding the Minimum Spanning Tree (MST) by growing a single tree from a starting vertex using a priority queue. | $O(E \log V)$ | $O(V + E)$ | Cluster analysis, network design where nodes are added incrementally. |
| **Bellman-Ford Algorithm** | Richard Bellman & Lester Ford Jr. | Single-source shortest path that can handle **negative edge weights** and detect negative cycles. | $O(V \cdot E)$ | $O(V)$ | Currency arbitrage detection, routing protocols where costs can represent loss/gains. |
| **Floyd-Warshall Algorithm** | Robert Floyd, Stephen Warshall, & Bernard Roy | **All-pairs** shortest paths (finding the shortest path between *every* pair of vertices). | $O(V^3)$ | $O(V^2)$ | Analyzing network connectivity, routing tables in small transit networks. |
| **Kadane's Algorithm** | Jay Kadane | Finding the **Maximum Subarray Sum** in a 1D array in a single pass. | $O(n)$ | $O(1)$ | Financial stock analysis (max profit/loss windows), image processing. |
